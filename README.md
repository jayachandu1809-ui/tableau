# 📊 Sales Performance Dashboard | Tableau

## 📌 Project Overview

This project presents an interactive **Sales Performance Dashboard** built using **Tableau**, designed to compare business performance between **2023 and 2022**. The dashboard enables users to analyze key sales metrics, monitor trends over time, and identify high-performing and underperforming product subcategories.

The goal of this project is to transform raw sales data into meaningful business insights that support data-driven decision-making.

## 🎯 Objectives

- Compare Sales Performance (2023 vs 2022)
- Monitor Total Sales, Profit, and Quantity
- Identify Highest and Lowest Performing Months
- Analyze Sales & Profit by Product Subcategory
- Track Monthly Sales and Profit Trends
- Enable interactive dashboard navigation and filtering
